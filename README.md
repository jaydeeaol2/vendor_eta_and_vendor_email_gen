# Vendor Repair Tracker

A mobile-friendly web app for tracking external repair vendors and jobs.

## How to Use

1. Open `index.html` in any browser, or host it on GitHub Pages
2. Add jobs using the **+ Add Job** button
3. View your jobs on the **Calendar** or **List** tab
4. Data is saved in your browser's localStorage — it persists across visits

## Hosting on GitHub Pages

1. Push this repository to GitHub
2. Go to **Settings → Pages**
3. Set source to **main branch / root**
4. Your app will be live at `https://yourusername.github.io/your-repo-name`

## Features

- Add, edit, and delete vendor jobs
- Track: vendor name, contact, escalation date, time, job type, status, notes
- Status color coding (Pending / In Progress / Done / Cancelled)
- Monthly calendar view with job chips
- Sortable list view with status filters
- Works on mobile and desktop
- No server required — runs entirely in the browser
